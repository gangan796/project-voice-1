1. 创建虚拟环境
   ```
   python -m venv venv
   ```
2. 激活虚拟环境
   - Windows
     ```
     venv\Scripts\activate
     ```
   - macOS/Linux
     ```
     source venv/bin/activate
     ```
3. 安装依赖
   ```
   pip install -r requirements.txt
   ```
   注意：需要镜像加速器，否则会安装失败
   ```
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```
4. 启动服务
   ```
   fastapi run main.py
   ```
