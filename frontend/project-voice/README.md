# project-voice

## Node版本必须20.19.0+或22.12.0
## 已经创建项目。
1. 主要是有Vue.js 3.5.17 用于构建用户界面。
2. 使用Vite 7.0.0 用于构建项目。
3. 使用Vitest 3.2.4 用于单元测试。
4. 使用Playwright 1.53.1 用于端到端测试。
5. 使用Vue-Router 4.5.1 用于路由管理。
6. 使用Pinia 2.3.0 用于状态管理。
7. 使用Vue-Test-Utils 2.4.6 用于测试组件。
8. 使用Vue-Tsc 2.2.10 用于类型检查。

## 根据输入法项目，可以用
1. Vue.js 构建用户界面。
2. Vite 用于启动开发服务器，支持热重载，修改代码，前端也会自动更新，无需频繁构建
3. Vite 还有一个强大构建工具，构建工具是用于生产环境，开发环境不需要。只需要启动开发服务即可
4. Vitest 用于单元测试，主要是为每个功能测试，以后会用上
5. Playwright 用于端到端测试，主要是调用API测试，用在调用API，方便测试，追查问题。
6. Vue-Router 用于路由管理，这是单页面组件路由，根据输入法项目，暂时用不上，为啥要用，以后说不定会有。
7. Pinia 用于状态管理，主要是管理状态，方便组件之间共享数据。
8. Vue-Test-Utils 用于测试组件，主要是为每个组件测试，以后会用上
9. Vue-Tsc 用于类型检查，主要是检查类型错误，方便开发。

## 项目结构
```
src
├── assets 资源文件——会被构建工具影响
├── components 组件——可以复用，所以放在这里
├── views 视图——每个页面，所以放在这里
├── App.vue 主组件——用于构建用户界面，所以放在这里
├── main.ts 主入口——用于启动项目，所以放在这里
├── router 路由——用于路由管理，所以放在这里
├── store 状态管理——用于状态管理，所以放在这里
├── types 类型——用于类型检查，所以放在这里
├── utils 工具——用于工具函数，所以放在这里
public 公共文件——用于公共文件，所以放在这里
index.html 主文件——用于构建用户界面——可以不用管，除非有特殊需求
vite.config.ts 配置文件——用于配置项目
vitest.config.ts 测试配置文件——用于测试项目
playwright.config.ts 端到端测试配置文件——用于端到端测试项目
package.json 项目配置文件——用于配置项目
tsconfig.json 类型检查配置文件——用于类型检查项目
e2e 端到端测试文件——用于端到端测试项目
```


重构项目核心最看重是src目录下，Router目录下可以不理会，以后需求的话会用上。
assets是资源文件，需要资源文件放在这个，会被构建工具影响
public是公共文件，放静态资源文件，不会被构建工具影响
stores是状态管理，用于管理状态，方便组件之间共享数据，与原有框架具有状态管理。
components是复用组件，可以复用，所以放在这里
views是视图页面，一般配合路由，可以编写也可以不用，一切看随缘
App.vue是主组件，用来配合views与components，而且App.vue是全局布局。
main.ts是主入口，用于启动项目，可以不理会
index.html是主文件，是配合main.ts，直接别管了。
